# Bounded Phase 1 method

Permission gaps, invalid dates, restricted classes and purpose mismatches go to the rejected queue. The accepted status is declared_permitted_unverified. This indexes metadata only: no fetch, actual content hashing, catalog lookup, permission authentication or redistribution authorization occurs. Duplicate links use supplied hashes and authority ordering; source records remain distinct. Economic indexing date is separate from accessed_at. Full original-input hash binds job reconstruction.

This is an offline draft evidence method, not a production source of record. Read [schema](schema.md) before mapping inputs. Native output is reconstructed from the separately retained input; independent expected results and professional review remain necessary.
