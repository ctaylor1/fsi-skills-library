# Investment banking

Primary owner: Investment Banking. This category contains M&A, financing, capital
raising, transaction models, coverage meetings, buyer targeting, deal diligence,
pitch preparation and process coordination. Reusable company/security research lives
in Investment Research and is consumed through explicit handoffs.

The former `investment-banking-research` paths have registered migration aliases.
Skill identifiers and native transaction methods remain unchanged by this move.
No transaction, outreach, delivery or professional approval authority is added.
