# Insurance Policy Transaction Package — draft

State case/account/policy identity, represented party, scope and as-of. Summarize the requested job and the native result status. Present the before/after or financial bridge with source versions and exact currency/basis. Separate known breaks, absent evidence, assumptions and disputed records. List source-linked actions for the responsible human, their dependencies and unresolved dates. End with the exact receiving workflow and native input still needed. Do not describe a drafted change as executed or an overdue balance as a lapse.
