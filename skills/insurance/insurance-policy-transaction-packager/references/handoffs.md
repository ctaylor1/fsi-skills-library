# Native handoffs

Use `life-annuity-contract-service-reviewer` for life value/rights decisions, `insurance-rating-worksheet-builder` for supplied rate arithmetic, `insurance-premium-billing-reconciler` for a subsequent actual billed movement, and `policy-wording-comparator` for text changes. A premium effect draft is not a posted invoice; carry the policy/version, transaction ID, dates, currency and unresolved issues into explicitly mapped native receiver input. Never send a renewal request as evidence of completed renewal.
