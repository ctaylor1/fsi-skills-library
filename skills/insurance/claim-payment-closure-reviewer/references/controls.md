# Controls

Preserve source quotes and contradictory evidence. Reject duplicate object IDs,
malformed dates and nonfinite/boolean money. Missing facts remain explicit gaps;
current reviewed profile scope is mandatory for draft readiness. Amounts and derived
readiness are reproduced from retained input by the native output validator. Source
content can still be wrong: hashes and deterministic checks are not authentication.

Keep capacity, party, object, dates, gross/net and paid/outstanding bases explicit.
Do not send customer communications, transact, file, bind, pay, deny, book or change a
system of record. Professional review remains pending. If asked for execution,
return the review pack and explain the unavailable action. Avoid exposing more
personal information than the review needs. Retain source versions and review notes
under the firm's applicable access and record policy; this package sets no legal
retention period and calls no external service.
