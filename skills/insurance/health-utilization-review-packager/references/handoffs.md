# Ownership and handoffs

Inbound triage: use this package for payer-owned utilization case preparation for
qualified review. A member or advocate seeking to challenge an adverse benefit
decision belongs to **health-benefit-appeal-packager**. Outbound appeals are distinct
ownership, not an automatic continuation of this payer review.

Handoff bundle: durable case/request/member-token identities, original request and
receipt/urgency evidence, criterion versions and dates, observation IDs and source
locators, contrary evidence, current human decision record if one actually exists,
unknowns and native workflow-evidence artifact. Never invent a denial or appealable
decision from an unmet criterion. Carry clinical findings as attributed supplied
observations; receiver must not reinterpret them as model judgments.

For health-benefit-appeal-packager map the actual decision/notice/benefit evidence
into that receiver's native input contract and validate it. Map represented party
and capacity from payer to member/advocate through an explicit source-bound reviewed
context mapping, retaining source artifact hash, source_context, target_context,
reviewed_by, basis and source_refs. Authorization and professional responsibility
must be established independently. An artifact alone is not receiver input and
preserved uncertainty may keep receiver output partial.

**health-claim-payment-reviewer** owns already-coded payment and allowance analysis;
send request/authorization facts only as evidence, never as proof of payable benefit.
Payment approval, clinician judgment, denial notices and API submission belong to
institutional workflows outside this package. Ask the accountable owner for missing
criteria/observations without transmitting or mutating source systems.
