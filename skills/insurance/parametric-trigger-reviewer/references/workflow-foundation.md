# Portable draft workflow runtime

Shared workflow-review runtime version 1.0 is a namespaced derivation of the existing insurance evidence/foundation design. Existing insurance helpers are unchanged. It provides finite Decimal amounts, immutable source retention, explicit context/source/effective-date checks, inherited uncertainty, native recomputation and CLI entrypoints. Domain methods own the substantive criteria. Sources are supplied, not fetched or authenticated.

Input shape violations fail with nonzero exit. Incomplete evidence may yield a valid needs-data artifact with dependent measures null. A zero validator exit is not professional or deployment acceptance. Use full result findings and native method limits. No connector, retry loop, customer action, system-of-record write or regulatory execution is installed.
