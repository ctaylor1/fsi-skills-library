# Method and boundaries

Review one contract/event against one explicitly selected terminal final reading.
The method is supplied-parametric-event-tiers-v1. All contract/source/applicability
and inventory requirements must be satisfied before dependent arithmetic. Preserve
historical readings and explicit predecessor relationships; never choose by largest
value, most recent timestamp alone, or convenient verifier.

Take the last satisfied tier in the strict severity order. With no satisfied tier,
the known schedule benefit is zero. Gross event scenario = min(tier payout, event
cap). Aggregate remaining = max(0, aggregate limit minus all cumulative net-paid
event balances). Current event outstanding = max(0, gross scenario minus cumulative
net paid for this event). Provisional unpaid scenario = min(aggregate remaining,
current event outstanding). The ledger is the reviewed aggregate-period population
for this contract, not a collection of unaligned payment snapshots. A payment above
the limit/scenario is a needs-review control break; no recoupment is inferred.

All amounts retain exact supplied arithmetic; no currency conversion, discounting,
interest or rounding convention is inferred. Unknown contract/metric/unit/location,
source inventory, ledger, finality, profile or upstream scope withholds all dependent
amounts. A zero scenario is not a claim denial. A positive scenario is not a payable
instruction or a coverage determination. Basis risk remains even when the index
comparison is known: the economic loss can differ from the parameter-based amount.
This method does not evaluate loss indemnity conditions, index science or exclusions.
