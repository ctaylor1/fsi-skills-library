# Ownership and handoffs

Inbound triage: payment-integrity/coding analysts own source-bound coded-line checks
and payment reconciliation. Clinical utilization evidence preparation belongs to
**health-utilization-review-packager**; member/advocate adverse-benefit challenges
belong to **health-benefit-appeal-packager**. This package does not select replacement
codes, issue denials or determine patient responsibility.

Handoff bundle: durable case/claim/line/chain/event IDs, complete original/replacement/
void history, source-bound exact terminal identity, current code/edit file profile,
provider contract allowance, independent benefit allocation and net-payment snapshot,
arithmetic identities, coding flags, variance questions and unresolved issues.
Preserve all native source artifacts and context mappings. Native output must be
mapped into receiver fields and validated; it is not a ready receiver request.

Clinical evidence questions go to health-utilization-review-packager with explicit
request/service mapping and actual qualified-review capacity. A payment discrepancy
is not evidence of medical inappropriateness. Appeal handoff requires an actual
adverse decision/notice, member representation and reviewed context mapping; a
coding flag or positive variance alone supplies none of those facts.

The institution's coding analyst resolves current-file and exact modifier questions;
contract/benefits owners resolve allowance/allocation contradictions; finance resolves
ledger reversals. Any revised code, adjudication, collection, recovery, payment or
communication remains a separate authorized institutional workflow. No duplicate
counting or duplicate execution is permitted during handoff.
