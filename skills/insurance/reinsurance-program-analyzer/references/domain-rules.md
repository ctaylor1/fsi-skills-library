# Domain rules and bounded method

Only sequential remaining_loss inuring is modeled. Each layer needs attachment, per-event limit, share, aggregate_limit and prior_erosion including explicit zeros; quota_share requires zero attachment and uses the same stated per-event cap. Capacity is denominated after participation. No automatic full participation, eligibility, unlimited limit, no prior losses, free reinstatement or premium formula is assumed. Reinstatement/variable premium amounts must already be supplied per scenario; the engine does not create them. Events must be uniquely identified, in chronological order and within the matching period. Scenario layers use shared IDs across compared programs; eligibility is an explicit reviewed list, and unknown IDs fail the affected pair. Alternative scenarios reset to each program's supplied prior erosion. Quantile inputs, marginal PML addition, aggregate stop-loss, hours-clause grouping, gross-basis overlapping layers and treaty coverage decisions are unsupported.

These implementation rules are engineering constraints. Applicable contracts and reviewed jurisdiction/product profiles control professional interpretation; public primers do not establish universal legal requirements.
