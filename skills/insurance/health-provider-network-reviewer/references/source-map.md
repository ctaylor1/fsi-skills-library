# Sources and freshness

Use purpose-authorized provider master/site-specialty inventory, plan-specific
executed contracts, credentialing and independent license evidence, dated directory
observations, complete eligible member roster, travel measurement matrix, and a
reviewed program/plan-specific threshold pack. Preserve IDs, effective dates,
versions, exact locators, scope, measurement method and source owner. An NPI file
can support identifier reconciliation only. It cannot replace credentialing.

Primary anchors verified 2026-10-04:

- [CMS Medicare Advantage and Section 1876 Cost Plan Network Adequacy Guidance](https://www.cms.gov/files/document/medicare-advantage-and-section-1876-cost-plan-network-adequacy-guidance-12-09-2024.pdf), last updated December 2024. The guidance treats network review as program-specific, uses specialty/county and time/distance criteria, and describes exceptions and different application circumstances. It motivates explicit scope and reviewed criteria; none of its thresholds, credits or procedures are adopted in this package.
- [CMS NPPES NPI Files](https://download.cms.gov/nppes/NPI_Files.html), mutable dissemination page. CMS states that NPI issuance does not establish licensure or credentialing. Use the exact dated file/version for supplied identifier evidence; the package makes no live lookup.

The institution must review the actual effective criteria for the program, plan,
geography, specialty and observation date. Refresh source versions and credentials
under the supplied review schedule. A 2024 guidance URL does not establish current
legal sufficiency. Cite each threshold and independent credential source. Where
source scope, review dates or population completeness are unresolved, withhold
comparison and route the specific missing evidence to its owner.
