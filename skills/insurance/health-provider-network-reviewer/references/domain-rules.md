# Method and limits

This method reviews a source-complete plan-specific provider/site/specialty
inventory and separately supplied contract, credential and directory observations.
Preserve exact identifiers and each legitimate site. A matching NPI, registration,
directory listing or network contract proves none of the other statuses.

A provider-site can qualify only when its supplied executed contract covers the
observation date for the plan and its explicit credential/license evidence is
verified with current review dates. Known exclusions remain visible for owner
review. Compare directory presence independently and report discrepancies.

For every reviewed threshold, require the exact full eligible member population,
its unique IDs and reconciled count. Require every eligible member's supplied travel
measurement to every eligible candidate provider-site in the same specialty and
geographic scope. Within the supplied maximum distance/time, count distinct provider
IDs per member, treating several qualifying sites of one provider as one provider.
A member meets the supplied test when that count is at least the supplied required
count. Member fraction = qualifying members / all eligible members. Compare it with
the supplied required fraction only after complete scope and measurement checks.

Known shortfalls produce review findings. Zero population, unknown travel values,
missing measurements, duplicate economic identities, stale/missing rule scope or
unreviewed populations produce null dependent comparisons. Decimal division uses
28 significant digits; threshold comparisons use exact rational fractions. No percentage is
renormalized to available records. Weighting is equal unique members separately
for each threshold, with no cross-specialty pooled adequacy score.

This deliberately bounded method does not geocode, route travel, infer available
appointments, assess capacity/quality, credential providers, determine licensure,
apply telehealth/exception credits, infer cross-geography access, or reproduce CMS
network submissions. Different programs require separate reviewed criteria and
method applicability; passing fictional or institutional thresholds is no regulatory
network-adequacy certification. No network or directory is changed.
