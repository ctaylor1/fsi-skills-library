# Source governance

Reviewed 2026-09-18: [ASOP 53, future P&C costs](https://www.actuarialstandardsboard.org/asops/estimating-future-costs-prospective-propertycasualty-risk-transfer-risk-retention/). Supports explicit data organization, exposure, historical adjustments, expenses and assumptions. The implemented single-cohort formula is a bounded library method, not an ASOP-mandated algorithm.

[CAS Basic Ratemaking](https://www.casact.org/sites/default/files/2021-03/5_complete_textref.pdf) is an educational reference for pure-premium and expense mechanics, not a binding standard or a current jurisdiction profile.

Actual decisions require the supplied policy/wording, source ledger and reviewed assumptions or operating rules, each with its version and applicability. Public sources do not authenticate those inputs. Recheck primary sources and jurisdiction applicability when recertifying; never copy fixture dates or statuses into a customer case.
