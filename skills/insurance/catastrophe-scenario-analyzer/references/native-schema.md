# Native input and output contract

Top level: case_id (durable nonempty string), as_of (real YYYY-MM-DD calendar date), context {capacity, represented_party, object_id, jurisdiction, line_of_business}, sources [{source_ref, version, optional as_of}], unresolved_issues (explicit string list), data (object), optional upstream_artifacts and reviewed context_mappings. Source identities are unique. Amounts are finite decimal-compatible numbers/strings or null when unknown; booleans, NaN and infinity are invalid. Supplied malformed shapes fail input validation; legitimate absent evidence produces explicit needs-data findings.

All methods require a profile with profile_id, version, source_refs, approved_by, effective_from, effective_to, jurisdictions and lines_of_business matching context, method matching data, and basis matching data. legal_basis_kind is internal-methodology or reviewed-applicable-law; the latter also requires adoption_ref resolving to a supplied versioned source. Profile version, publication/effectiveness and actual local adoption are distinct. Source evidence must not postdate review as_of. Profiles are reviewed input, not a source-authentication mechanism.

`data`: method, basis, object_id, currency, valuation_date, profile, model_id, model_version, events_complete boolean, events list, thresholds list of unique nonnegative finite amounts. Each event requires object_id, valuation_date, basis, currency, source_refs, event_id and loss (nonnegative or null).

For method=`annual-joint-sample-v1`: years_complete and joint_distribution_supplied must be true; years require year_id, weight, all common bound fields and sources. Events also require year_id and occurrence_id. year_id identifies a simulated annual state, not a calendar year; no event date is fabricated. Weights are probabilities, not counts, and must sum exactly to one. A complete empty events list can support all-zero annual states.

For method=`event-rate-aal-v1`: rate_semantics=`expected-occurrences-per-year`, loss_semantics=`expected-additive-loss-per-occurrence`, event annual_rate is nonnegative. Years are not used. Rates are not normalized. Outputs distinguish aggregate_aal, mean_annual_max_occurrence_loss and exceedance_probabilities; unavailable curves stay null. annual_states retain the exact weighted sum/maximum calculation.

Output includes retained source_document, findings with code/severity/source_refs, native results, completeness/evaluability, unresolved_issues and insurance-evidence/1.0 artifact. ready-for-review is draft readiness only. approval stays not_requested, execution not_performed, action_taken false and human_review_required true. Source/document metadata are retained for recomputation; do not use production PII in fixtures. Local list size is bounded to 10,000 items; larger portfolios require reviewed upstream partitioning and an explicit reconciliation method, not silent truncation.
