# Handoff boundaries

One primary job owns each result. Each transfer preserves durable case/object IDs, original
input/output identity, source fact mapping, period, product/audience/classification and all open
issues. Sender and receiver must run their native validators against detached originals, then
review an exact field map; names resolving does not imply schema compatibility. No generic
wrapper grants action rights or professional acceptance.

- `model-validation-assistant`: Model performance/validation mandate; compliance procedure testing does not replace it.
- `audit-evidence-packager`: Assembled workpapers for authorized audit; package delivery is not an audit opinion.
- `compliance-remediation-evidence-reviewer`: Accepted failed-control findings, tested sample, coverage limits and retest criteria.

Institution-specific Legal, HR, DPO, audit and control-room professionals may be human handoffs
without an installed automated skill. Preserve their ownership; do not invent a callable adapter.
