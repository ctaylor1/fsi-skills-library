# Handoffs and distinct ownership

This package owns its stated primary artifact. Triage can identify a needed specialist; do not represent triage as the specialist investigation. Transfer durable case ID, exact entity/activity/period scope, original source references, facts, native output, unresolved issues, purpose/audience and producer validation evidence. Receivers use their own input/output contracts and reviewed exact field mappings; names do not imply schema compatibility.

- `compliance-control-testing-assistant`: Run a separately scoped control test.
- `compliance-control-testing-assistant`: Design a test plan under an evidenced mandate.
- `compliance-remediation-evidence-reviewer`: Plan supported issue remediation.
- `compliance-program-designer`: Improve risk/control/accountability/resources design.

Legal owns contested rule interpretation. Institutional reviewers own final decisions and independent assurance mandates. Live actions require separately authorized adapters and their own controls.
