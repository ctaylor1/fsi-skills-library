# Explicit professional handoffs

Native helper copies run independently under Python 3.10+ standard library. Other skills are separately installed professional workflows, with no runtime imports or assumed schema compatibility.

| Receiver / owner | Evidence carried and boundary |
|---|---|
| transaction-monitoring-scenario-designer / Design Lead | Source-bound risk, exact population/data/mapping, observed gaps and change proposal. A review ID is not a scenario ID; an explicit reviewed object conversion is required. |
| transaction-monitoring-effectiveness-reviewer / Effectiveness Review Lead | Frozen scenario/engine version, population/cohort/window, reconciled extracts, exact observations and accepted reference labels. A design does not prove any execution or detection. |
| compliance-control-testing-assistant / Mandated Testing Lead | Control objective, test mandate, population/sample/workpapers, independence evidence and unresolved exceptions. Operational QA, second-line monitoring, independent testing, model validation and audit remain different mandates. |
| financial-crime-technology-controls-reviewer / Technology Controls Owner | Versioned engine/vendor/model/copilot/real-time/graph control requirements and gaps. Supply underlying exports, limits and actual implementation evidence; no implied deployment acceptance. |
| model-validation-assistant / Model Risk Owner | Model inventory/classification, intended use, version, development/evaluation evidence, performance/drift and limits. Deterministic rule checks are not substantive model validation; excluded generative/agentic tools retain separate institutional governance. |
| data-quality-issue-investigator / Data Owner | Actual lineage, population/amount reconciliations, missing/late/duplicate records and their evidence. General data diagnosis remains there. |
| solution-architecture-planner / Architecture Owner | Supplied integration requirements, boundaries, dependencies and gaps. Architecture design is not duplicated here. |
| data-product-value-evaluator / Value Owner | Supported unit costs/outcomes and their exact accounting/window/cohort bases. Value/ROI requires its separate assumptions and contract. |
| workflow-automation-assessor / Workflow Owner | Proposed shadow, reconciliation and approval gates, manual review and rollback requirements. Workflow automation/control design remains separate. |
| compliance-remediation-evidence-reviewer / Remediation Owner | Actual gaps, owners and supporting retest evidence. Detection counts do not establish issue closure. |

Validate producer native output against its detached original and receiver intake against its separately retained supplemental evidence. Preserve complete source facts/versions, request/object IDs, context, dates/cutoff, confidentiality/audience, claims and unresolved issues. Same-object/context/time/audience adapters cannot implicitly convert design to effectiveness, legacy replay to accepted labels, or monitoring to alert/investigation/SAR. Cross-object, legacy/Foundation, audience or cutoff changes need a separately reviewed adapter; otherwise remain native-only with an explicit professional handoff.

Keep the transitional transaction-monitoring-scenario-evaluator installed and unchanged. Its structuring, aggregate flow ratio, geography, velocity and cash-intensity five-rule method remains a bounded replay with its original contract. There is no alias, rename, replacement or automatic conversion.
