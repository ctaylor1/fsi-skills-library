# Handoff boundaries

Preserve request/object IDs, full institution/entity/purpose context, assessment/cutoff, source/fact versions and locators, source access/classification, original input hash and unresolved issues. Sender and receiver must each validate against their detached originals. These packages have distinct native objects; a named receiver is a professional route, not a callable schema adapter. Do not wrap or relabel this artifact as another native result. Prepare an explicit reviewed field map and collect the receiver's own intake.

| Receiver | Purpose and retained limit |
| --- | --- |
| sanctions-match-investigator | Investigate a particular potential match with identity evidence; sample labels do not determine match identity. |
| sanctions-exposure-reviewer | Review activity, ownership, regime and authorization exposure; screening outcomes do not clear a transaction or establish blocking. |
| compliance-control-testing-assistant | Establish mandate, sample/workpapers, acceptance and independence evidence; this screening review issues no assurance opinion. |
| compliance-remediation-evidence-reviewer | Carry exact observed exceptions, missing coverage, owner-defined remedies and retest criteria; no remediation closure is implied. |

Institution sanctions policy, Legal, data engineering, vendor risk, business continuity, model validation and independent testing owners remain human routes where no compatible package adapter is supplied. No access grant, communication, evidence upload or operational action occurs.
