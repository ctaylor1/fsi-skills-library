# Domain ownership and handoffs

The routes table owns discovery. A route is not a native data adapter. Use the actual
receiver input schema and source-bound field mappings before handoff; preserve issues
and return consultations to the original case owner.

| Job | Existing owner / boundary |
| --- | --- |
| Payment scams/intervention | `payment-fraud-and-scam-investigator`; disputes, recovery and reimbursement retain payment owners |
| Payment fraud controls | `payment-fraud-control-evaluator`; tuning analysis does not deploy rules |
| Insurance fraud/SIU | `insurance-fraud-referral-reviewer` and `insurance-fraud-pattern-analyzer` |
| Market surveillance | `surveillance-alert-triager` and `market-surveillance-alert-investigator`; no trading authority |
| Individual recommendations | `investment-recommendation-evidence-reviewer`; no generic thematic conduct substitution |
| Individual complaints | `complaint-resolution-assistant`; thematic recurring outcomes belong to `customer-conduct-outcomes-reviewer` |
| Promotion/supervised communications | `financial-promotion-reviewer` owns external cross-sector promotions; `communications-compliance-reviewer` retains CM supervision/records support |
| Technical architecture | `solution-architecture-planner`; CFC supplies domain evidence/authority requirements |
| Automation suitability | `workflow-automation-assessor`; no execution authority is granted |
| Provider risk | `third-party-risk-assessor`; provider claims need independent acceptance evidence |
| Privacy | `privacy-impact-assessment-assistant`; privacy/controller/DPO accountability |
| Model/AI governance | `model-validation-assistant` and `ai-risk-assessment-builder`; declared mandate and applicable model scope |

Legal interpretation, release/submission, customer acceptance, transaction restrictions,
professional attestations and audit opinions remain with their designated humans and
trusted institutional processes. No catalog alias or router response supplies those.

Phase3 adds explicit same-subject design-to-effectiveness and single-case investigation-to-QA [review projections](review-projection.md). No other cross-object or adjacent native conversion is implemented.
