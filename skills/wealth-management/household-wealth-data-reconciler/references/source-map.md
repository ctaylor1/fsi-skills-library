# Sources

Use authorized CRM scope/mapping records, custodian or institution statements, client-provided held-away statements and lending balances. Collect the source owner, dated reference and review validity. The human reviewer resolves conflicting source authority; there is no automatic custodian-versus-client precedence.

A valuation policy supplies maximum age and version, not the calculator. Independent totals must use identical account scope, currency and household-share basis. Synthetic fixtures are test data, never production policy. Scripts do not fetch, verify, write or authenticate any external source.
