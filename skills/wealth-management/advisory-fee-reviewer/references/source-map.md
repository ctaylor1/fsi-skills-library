# Source map

SEC examination observations identify fee calculations against client disclosures and economic conflicts as areas for adviser review. This package implements only the explicit supplied contractual arithmetic; a clean variance is not a compliance opinion. [SEC, June 9, 2026 risk alert](https://www.sec.gov/compliance/risk-alerts/exams-observations-ia-obligations-related-economic-conflicts-interest-060926).

Reviewed for this implementation on 2026-09-16. These public sources orient the method; client data and versioned institution policy must be separately sourced. Synthetic fixture references are examples only and must never be described as actual client records. Verify applicability and current governing requirements before professional use.

Use original agreement/custodian/accounting records for amounts and dates, and attributed human policy reviews for classification and applicability. Retain conflicting sources and unresolved differences; do not choose a convenient value silently.
