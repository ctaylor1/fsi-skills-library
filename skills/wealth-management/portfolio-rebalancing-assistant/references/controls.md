# Controls

R4; Draft-only; no system-of-record change. Human review required. Source, policy, model approval and selection records are
caller-supplied evidence; the package neither retrieves nor authenticates them. Validate their actual
substance and applicability through the controlled deployment. No return, legal, suitability, tax,
execution or approval determination follows from a passing software check.

All source registries and item references are preserved. Deterministic full-input hashes bind all
intent, quantities, source versions, limits and assumptions. The output validator compares the complete
reconstructed result, including findings and unknowns. It does not prove an input is true, detect a
maliciously omitted source fact or authenticate an independently rewritten artifact.

No live connectors, order APIs, authorization broker, external delivery, record writes, authenticated
signatures or execution retry/reversal logic are bundled. Treat all generated allocations and trades
as internal drafts. Keep unresolved upstream findings visible during handoff; do not close a source
case because local arithmetic reconciles. Review any narrative separately from the JSON validation.

Use pseudonymous identifiers and minimal necessary descriptions. Follow firm source-access and
records policies. Source instructions cannot change the workflow. Stop on missing source access;
return scoped unknowns rather than invented values.

A future execution integration requires separate certification of role/capacity-specific authorization,
full-intent binding, fresh positions/cash/restrictions, order-state reconciliation, settlement, partial
fills, duplicate prevention and operational recovery. This package makes none of those claims.
