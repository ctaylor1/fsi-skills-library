# Handoffs

- `household-wealth-data-reconciler`: resolve lot, basis and cross-account inventory.
- `portfolio-rebalancing-assistant`: prepare a separately reviewed transition draft with tax findings retained.
- `investment-recommendation-evidence-reviewer`: assemble recommendation evidence without granting approval.

Every handoff carries request/household identifiers, capacity, as-of period, source registry and item citations, originating artifact ID/hash, calculated evidence and all unresolved findings. Map them into the target input explicitly and run its validator. Target readiness never closes an upstream issue. Tax, legal, insurance or billing determinations go to the appropriate authorized professional; package names do not establish specialist credentials. No automated downstream execution is bundled.
