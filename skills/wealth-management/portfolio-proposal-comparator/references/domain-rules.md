# Comparison economics

Weighted fund expense bps = sum(holding weight × expense bps). This is complete only if all holdings
have sourced expense data and weights sum to one. Keep a known subtotal separately from the unknown
total. Ongoing modeled bps = weighted expense + advisory + custody + other annual costs. Ongoing
modeled dollars = portfolio value × bps/10000. First-year modeled dollars add supplied one-time
transaction costs. Zero fees must be explicitly sourced. Check any supplied reported costs and
holding market values. This is the supplied component scope, not a claim of all possible lifetime costs.

Each constituent contributes holding weight × within-holding exposure weight. Aggregate the same
issuer/sector/asset class across direct holdings and multiple funds. Fund sponsors are not automatically
substituted for constituent issuers. No broad/diversified string suppresses exposure. Incomplete coverage
means the true maximum is unknown; the known maximum is a lower bound that can still exceed a supplied
limit. Overfilled look-through is invalid economics and contributes no misleading exposure total.

Liquidity compares sourced days-to-liquidity with the supplied horizon. Unknown days do not mean liquid.
Conflict flags preserve explicit proprietary/revenue-sharing/cheaper-share-class facts; unknown booleans
remain unknown, not false. Flags request professional review, not disqualification or recommendation.
Missing horizon or limits remain unresolved; no regulatory thresholds are invented.

Pairwise differences are right-minus-left, preserving proposal order. Compare cost rates only when both
are complete. Dollar comparisons also require identical currency and portfolio value. No rank or winner
is produced. Portfolio labels do not establish investor-objective fit. There is no turnover-based tax
proxy or fabricated return forecast; route real tax questions to tax-aware-investment-reviewer.

Floating-point tolerance1e-8 for weights and0.01 currency units for independent amount tie-outs are
numerical conventions, not an investment/compliance rule. Prices and costs remain snapshot estimates.
