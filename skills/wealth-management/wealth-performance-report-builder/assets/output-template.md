# Wealth Performance Report Builder — internal draft

Request / household / professional capacity / as of / artifact ID / input hash / reviewer:

## Scope and reporting method

Identify household/accounts, reporting period, source dates, boundary valuations, flow/fee convention and exclusions.

## Performance and reconciliation

Show account and household cumulative net/gross returns, ending value, observed fees and external flows, and comparison with the official record. Label suppressed returns and partial totals. Explain internal transfers and avoid averaging account returns.

## Benchmark comparison

Show the approved benchmark rationale, period/currency coverage, cumulative return and net percentage-point spread, or the explicit reason no benchmark applies.

## Findings and next actions

List each missing observation, reconciliation difference and upstream concern with evidence, owner and requested follow-up. No annualization or GIPS assertion is made.

## Evidence and review record

List sources with owner, reference, date and validity; tie material statements and calculations to item citations. Record methodology version, unresolved issues and disposition owner. Human review required; not delivered and no action taken.
