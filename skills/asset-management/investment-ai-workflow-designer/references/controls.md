# Interpretation and acceptance controls

- Record the accountable investment decision and human checkpoint before introducing an assistant. No score, candidate flag or internal draft transfers investment authority.
- Obtain actual license purpose, principal entitlement, portfolio/client barriers, retention/deletion and model-provider training terms. A supplied approved/allowed string is not live permission evidence. Test permitted and denied operations against institution-owned identity infrastructure separately.
- Freeze the evaluation manifest, label protocol and data snapshots before the experiment. Identify semantic duplicates, time leakage, survivorship and model-provider exposure independently of this identity-based method.
- Retain actual runtime observations for failures, denied requests, retries and effects. An abstention in final text cannot erase a prohibited read, write or message already performed.
- Inspect all missing cases, unknown labels and cost/latency coverage before interpreting rates. If denominators or source quality differ, do not compare experiments as equivalent populations.
- Evaluate realistic stale prices, client/portfolio crossovers, instruction-bearing research documents, unavailable connectors and tool schema changes. Passing the included deterministic fixtures proves only bounded helper behavior.
- Version changes require a new experiment. Resolve shared-owner findings and model/data/technology-owner acceptance before any pilot or deployment approval. Preserve rollback, kill-switch, incident owner and periodic reassessment in the operating design; this package executes none of them.
