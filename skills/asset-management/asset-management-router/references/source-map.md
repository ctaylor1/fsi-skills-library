# Source map

The router is an offline planner over supplied declarations. It retrieves no market,
accounting, legal or client data. The natural-language request is interpreted by the
calling agent; the calculator receives explicit intent identifiers.

| Source | Use | Limits and review |
| --- | --- | --- |
| Original user request and supplied subject identity | Establish the professional job, requested action and subject | Retain the original; do not invent authority, objectives or missing scope. Ambiguity needs clarification. |
| `routes.json` | Versioned primary/supporting package names, accepted subject types, scope and overlays | A route is not an implementation or an installed-package inventory. |
| `capabilities.json` | Current versus planned capability map | Read the receiving package's current native contract before use; a bounded method is not the entire professional workflow. |
| `migrations.json` | Translate former paths and names | Former names are lookup aliases, not additional installed packages or engines. |
| Request `available_skills` | Caller-supplied inventory of exact canonical package names | Omitted inventory produces `unknown`; `[]` means every referenced package is `not_installed`. No filesystem/connector discovery or authentication is performed. |
| Request `as_of`, `subject`, `unresolved_issues` and action | Bind the route plan to the supplied request | The date is a real calendar date; no evidence chronology or professional facts are inferred from it. |
| Receiver native input, original source material and method record | Build a separately validated workflow handoff | Use the handoff contract. A route plan does not supply missing positions, returns, NAV, legal terms or source-use rights. |

Mode availability is reported at the containing package level. For example, quality
and cross-source comparison use `investment-data-quality-reviewer`; do not put a
retired comparison-package name in the inventory and report the containing package
as installed. Canonical package installation alone does not prove every mode accepts
the requested input. Validate the selected mode's native contract separately.

The complete routing input is hashed. This binds supplied values, including inventory
and unresolved issues, to the deterministic output; `source_truth: unverified`
explicitly preserves the absence of source authentication. Retain detached input in
approved storage and use it in output validation. Regulatory sources for an eventual
workflow require entity, activity, jurisdiction, effective date and legal status; the
router does not decide applicability or supply a legal rule pack.
