# Supplied sources and deployment prerequisites

Use authorized, versioned original records for the named business scope. Preserve source record identifiers, effective/observation dates, source owner and declared input configuration. Source identifiers and hashes do not authenticate a record or establish its permission.

The implemented input contract is [schema](schema.md). This package does not retrieve, connect to, update or certify enterprise sources. Source access, entitlements, retained evidence and any deployed tools require institution-owned contracts and review. Do not replace absent observations with fixture values.
