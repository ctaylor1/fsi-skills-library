# Source map

| Source | Role and hierarchy | Required provenance |
| --- | --- | --- |
| Firm review policy | Defines only the supplied comparison requirements in the recorded capacity and jurisdiction | Version, owner, effective/valid dates and source IDs |
| Client/account/manager documents of record | Supports factual observations and terms; conflicting versions remain unresolved | Source locator, owner, observed date, validity date and item links |
| Client or manager assertions | Attributed statements and assumptions, not verified facts | Dated interview/statement locator and individual source IDs |
| Specialist/upstream artifacts | Carries prior findings and assumptions into this scoped review | Artifact ID, unresolved/resolved status, cited evidence |

This package includes no universal legal, tax, insurance, actuarial or investment thresholds.
Supplied policy/assumptions control deterministic comparisons only; the qualified human verifies
applicability and actual source content. Source registry freshness is checked relative to the
request as-of date. An in-date document reference cannot prove the extracted value is true.
Fixture sources are synthetic and must never be reused as production evidence.
