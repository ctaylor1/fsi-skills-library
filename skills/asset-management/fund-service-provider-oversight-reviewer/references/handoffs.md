# Handoff boundaries

Triage into this package when the supplied-input job matches its documented mode. For unresolved evidence, send the original source reference, request/object/date/currency, method, issue details and exact native result to the accountable reviewer. Return broader requests to asset-management-router with the missing capability identified.

- `fund-nav-control-reviewer`: separate adjacent job; read its actual native contract and map required fields explicitly before receiver input validation. Installation and schema compatibility are not implied by this link.
- `asset-management-router`: request operating-model planning as a separate job. The investment-operating-model-planner adapter is planned for Phase 3 and cannot receive a native handoff yet.

Carry the detached original-input reference/hash and all unresolved issues. No complete raw source snapshot is embedded in the native result. Build a separately validated workflow packet only after producer output validation and receiver-native input mapping. Metadata compatibility alone does not authorize a workflow launch.

Do not send professional conclusions as validated arithmetic fields or reuse a result for a different object/date/audience. This package consumes evidence and produces draft workpapers; only the appropriate authorized operator can perform external delivery or system-of-record action.
