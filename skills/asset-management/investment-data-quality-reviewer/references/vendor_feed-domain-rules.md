# Bounded Phase 1 method

One internal source versus one vendor per run. Duplicate cells block computation. Future/invalid dates and mismatched units, currency or valuation dates produce not_comparable. A stale finding does not suppress a concurrent value mismatch. Break count is number of findings; break_cells counts distinct affected cells, preserving matched_cells + break_cells = union cells. Unknown stale-materiality is null. No canonical source/value is selected. Comparison, pricing investigation, reference-data stewardship and corporate-action interpretation remain separate decisions.

This is an offline draft evidence method, not a production source of record. Read [schema](vendor_feed-schema.md) before mapping inputs. Native output is reconstructed from the separately retained input; independent expected results and professional review remain necessary.
