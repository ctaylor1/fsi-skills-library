# Bounded Phase 1 method

Duplicate security keys require explicit upstream consolidation. Exclude missing, invalid, future observations and future effective dates. Use latest effective observation per source, preserve conflicting same-date observations, then apply the declared source rank. Staleness and disagreement are independent findings. All proposals require steward review. ISIN and CUSIP structural checks are bundled; other schemes require review rather than invented validation. Source hierarchy is a supplied selection policy, not a verified license. Identity conflicts have no proposed identity resolution.

This is an offline draft evidence method, not a production source of record. Read [schema](schema.md) before mapping inputs. Native output is reconstructed from the separately retained input; independent expected results and professional review remain necessary.
