# Controls and acceptance

Owner: Fund accountant. Risk tier R3; draft/read-only calculations only. Input source/date/audience failures stop calculation. Missing domain measures produce the documented unavailable result; arithmetic success cannot clear an unresolved issue.

Use request_id plus object_id and the complete input_hash as durable review identity. Preserve every upstream unresolved issue. Calculation method/version, original sources and output must be retained according to the deploying institution retention policy; no retention period is invented here.

Separate preparer, reviewer and authorized system-of-record operator. Neither a supplied-cleared/supplied-approved label nor a hash establishes authenticated approval. No software routine posts, settles, closes, accepts, delivers or certifies. External delivery requires a separately authorized audience projection and professional review. Keep raw originals detached; source_input in native output is forbidden.

Investigate source/model exceptions with the data/control owner; return unsupported methods to triage. Halt on invalid schemas, stale references, arithmetic domain overflow, altered outputs or missing identity. There are no retries against live systems.

Release acceptance remains open: domain SME, control owner, legal/compliance where applicable, accessibility, model-risk and deployment-owner review. Synthetic goldens and independent arithmetic regressions evidence bounded behavior, not production fitness or professional acceptance. Retire this bounded method when an accepted enterprise engine supplies the same governed job; retain migration/lineage evidence.

Actual period endpoints, received/recorded events and dated valuation observations must also be on or before the request as-of, knowledge cutoff and their own source known-at date. Earlier source metadata cannot validate a later completed observation. Contractual due/payable dates, validity expiries and prospective terms may remain future dated. These chronology checks validate supplied declarations only.
