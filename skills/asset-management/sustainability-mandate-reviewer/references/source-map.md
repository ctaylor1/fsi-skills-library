# Source map

Operative evidence is the supplied investment mandate, approved metric definition, reconciled holdings snapshot and dated source observations. Preserve metric/reporting-period definitions, units, issuer mapping, denominator scope, estimated flags and provider versions. Example thresholds and holdings are synthetic and are not law.

Primary references checked 2026-10-04:

- [GHG Protocol Scope 3 calculation guidance](https://ghgprotocol.org/scope-3-calculation-guidance-2) provides category-specific methods, including investments. This package aggregates supplied scalar metrics; it does not implement the category 15 inventory methodology or estimate financed emissions.
- [ESMA fund-name guidelines announcement and linked final report](https://www.esma.europa.eu/press-news/esma-news/esma-guidelines-establish-harmonised-criteria-use-esg-and-sustainability-terms) describe naming criteria and exclusions. Their actual applicability requires the current text and institution-specific review; a local metric result is not naming approval.

These references inform the professional boundaries. No hard-coded legal threshold or universal sustainability rule pack is installed. Refresh authoritative text when preparing an actual jurisdiction-specific mandate review.
