# Mode and adjacent-skill handoffs

Modes have incompatible native schemas. An output of one mode is not an input of the other. A human-reviewed adapter must map actual source fields, preserve unresolved issues and verify the receiving schema; none is supplied automatically here.

- [evidence boundaries](evidence-handoffs.md)
- [policy boundaries](policy-handoffs.md)

The aliases in the migration registry identify one canonical package and an explicit mode; they are not duplicate installed skill packages.
