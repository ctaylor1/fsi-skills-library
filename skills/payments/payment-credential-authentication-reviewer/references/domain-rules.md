# Domain boundaries

Network-token domain restrictions and token requestor identity differ from merchant
vault token portability. Reprovisioning to another device/merchant is a new reviewed
lifecycle event, not permission inherited from a previous token. Inactive, revoked or
unknown status cannot support a current-use assessment. A supplied expiry interval
must cover the analysis date; deployment must additionally check actual execution time.

A challenge request, a frictionless path or a passkey sign-in is not enough to infer
authentication. Final provider outcome and exact binding are separate evidence.
Authentication is distinct from payment intent, issuer authorization and settlement.
Account updater can deliver updated information even when authorization is declined;
updates do not revive consent or override opt-out. No liability shift, exemption or
SCA compliance decision follows from the protocol label. Current scheme, jurisdiction
and institution requirements belong to a scoped specialist review.

This normalized offline assessment does not implement protocol verification,
cryptography, remote revocation propagation, account updater or token provisioning.
