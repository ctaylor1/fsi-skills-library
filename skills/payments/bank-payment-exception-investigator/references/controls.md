# Controls and authority

R3 read-only evidence assembly and recommendations. No case closure, persistence, scheme response, payment execution, regulatory filing, or final adjudication is implemented. A human owner decides the next action.

Input validation enforces declared bank/ISO scope, finite monetary values, cited timezone-aware messages, and basic configuration validity. Output validation recomputes the source-derived package, checks allowed recommendation dispositions, preserves priority overrides, and rejects action/closure claims.

All artifacts carry source lineage and supplied-evidence limitations. A hash is not authentication; case ownership must be accepted in the actual case system. Return/recall eligibility is supplied case evidence and must be confirmed against the governing scheme and current state before any action.

Run package regression tests and executable eval commands. Conceptual routing prompts remain model evaluation specifications, not completed model tests.
