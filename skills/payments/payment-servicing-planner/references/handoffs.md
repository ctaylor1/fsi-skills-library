# Handoffs

A handoff carries the durable request ID, jurisdiction/participant, exact source-bound result and registered evidence, all findings/upstream unresolved issues, expected next artifact and current action boundary. The receiving skill must pass its own input validator. Review-ready analysis is never an authorization token.

Servicing → `payment-initiation-control-reviewer` for exact linked funds-movement review; `payment-lifecycle-diagnoser` for observed outcomes; `issuer-payment-dispute-reviewer` for statutory redress; `payment-fraud-and-scam-investigator` retains fraud-case ownership. No ordinary servicing plan routes to repair as an execution shortcut.
