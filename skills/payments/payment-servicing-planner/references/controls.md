# Controls

Risk tier R3. Generated analyses and plans are draft decision support, with human adjudication required before relying on regulated controls. Approvals, identity authentication and payment execution occur in the institution's authorized systems and are not implemented here. No repair approval, login, public scheme profile or source pointer grants payment authority.

Retain request ID, original evidence snapshot, source dates, exact output and unresolved issues in the caller's governed record. A request ID is supplied, not allocated or persisted. Use opaque customer/account references; do not provide credentials, full PAN or authentication secrets. Missing, stale or conflicting evidence remains a gap. No native CLI accepts execute. Tampered outputs fail source-bound recomputation, and `--input` additionally binds to separately retained input.

All fixtures are synthetic. Independent scenario testing, specialist acceptance and operational security controls are separate from these deterministic checks.
