# Read-only reconciliation controls

R2 analytical output; no journal suggestions, reversals, payment changes or ledger writes.
A discrepancy alone does not establish which side is wrong, the booking entity, correct
account, tax treatment or authorization. Investigation handoffs cannot grant authority.

Use masked references and the minimum source rows needed. The supplied evidence status is
preserved; a nonempty citation or content hash is not authentication, inspection or sufficiency.
Retain source dates, partition scope, configuration version and review history under local
records policy. Do not include raw PAN, sensitive authentication data or credentials.

External delivery requires the reviewer's authorization; bundled scripts neither deliver
messages nor connect to systems. Validate source structure before calculating and recompute
the full result before presentation. Explanatory prose must preserve unresolved issues and
cash uncertainty; never present a hypothetical correction as reconciled cash.

Fixture and script tests establish deterministic behavior only. Independent domain-owner
review and real-model workflow testing are required before deployment.
