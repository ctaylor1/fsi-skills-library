# Interpretation controls

R2 read-only explanation. Input validation selects a documented normalized profile and rejects structural/monetary problems. Unsupported family structures remain classification-only. Output validation regenerates the interpretation from the source, checks the offline-validation flags, and screens payment directives and regulated determinations.

Supplied source references and code-set labels are not verified standards citations or authenticated retrieval. Cite exact governing scheme/version documentation when making a production-specific claim; if unavailable, state the limitation. Never infer a complete rulebook from representative code dictionaries.

Missing data must stay missing, not zero. Source statuses are reported assertions, not independently established finality. A handoff may request further interpretation or casework but cannot authorize a payment action.

Run `scripts/regression_tests.py` plus executable eval commands. They cover the adapter and actual validator, not raw XML conformance or real-model answer quality.
