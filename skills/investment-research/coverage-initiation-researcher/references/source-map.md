# Supplied evidence and source boundaries

This native method uses supplied JSON only. Source indexing, original-document extraction, identity resolution, market data and institutional configuration must be provided through separately approved access. No live connector or entitlement authentication is bundled.

Preserve original document/record identity, locator, version, reporting period, availability/as-of dates, currency/units, accounting basis, licensed purpose and audience in the retained evidence. A citation string, source tier, approval flag or matching hash is not independent source verification. Conflicts and missingness remain open issues; do not select a preferred fact silently.

Use the native [contract](phase1-contract.md) and read-only approved originals. A public document does not establish redistribution rights for a derived dataset; a supplied private source does not establish clearance. External projection requires separately reviewed confidentiality, licensing and institutional rules. Never copy raw source input into native outputs.
