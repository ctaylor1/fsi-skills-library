# Phase 2 analytical mode

Select schema_version=ir-phase2/1.0. Required common context: request_id, purpose=internal-research, audience=internal-review, subject type/id (security includes issuer_id), as_of/use_on dates, knowledge_cutoff date or aware timestamp, information_barrier, source metadata and top-level evidence_refs. Every row citation must appear in the top-level evidence set; unknown source identity, timing or rights withholds the full projection. The retained original is mandatory for output reconstruction.

Require valuation_subject={security_id,share_class,share_count_basis} on the intake and every method; all three must be known and match exactly. Require the common financial basis currency/unit/accounting_basis/consolidation_scope/period_id. sections[] uses eight expected section identifiers and claims[] with text/evidence_refs. method_outputs[] requires unique method_id, method_version, subject_id, as_of, the same financial basis, nullable value_per_share, evidence_refs and issues[]. model_review has state not-supplied/review-required/native-reviewed and issues[]. Optional weights must cover all method IDs and sum to one. Accept only exact issuer/as_of/basis matches, cited nonnull values and no method issues. Produce the range and optional supplied weighted midpoint; never force a blend. Carry model issues and block readiness for missing evidenced sections or review. A manually supplied native-reviewed label is not authenticated; use the reviewed adapter with actual producer input/output for native handoffs.

Read the synthetic paired phase2-input.json/phase2-valid.json in evals/files. Output is the source-bound ir-analysis/2.0 draft shape with results, lineage and unresolved issues. Native validation proves reconstruction, not source authenticity, institutional acceptance or approval. Legacy Phase 1 inputs retain their original API and fixtures.
