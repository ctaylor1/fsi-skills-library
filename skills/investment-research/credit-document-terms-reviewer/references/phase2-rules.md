# Method and limitations

Apply only executed documents effective at as_of and an exact predecessor version chain. Amendments use reviewed explicit add/replace/delete changes; replace/delete verifies the prior value hash. Unreviewed changes, hash mismatches and chain gaps remain issues; affected values are withheld, never legally interpreted. A covenant adapter can map only an already reviewed explicit native definition with a matching instrument and governing document version. The legacy Phase 1 extraction contract remains supported without schema_version.

Software checks establish finite arithmetic and exact reconstruction only. Domain, legal and institutional acceptance remain not established.
