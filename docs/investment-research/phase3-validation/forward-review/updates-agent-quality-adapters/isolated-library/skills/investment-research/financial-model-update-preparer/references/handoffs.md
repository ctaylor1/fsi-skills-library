# Handoffs

The declared `model_kind` determines the only eligible native receiver.
Keep the original update request and source-bound native proposal together under
institution controls. A reviewed adapter must reconstruct this producer, require
`receiver_input` to equal `results.candidate_input` in full, verify its digest,
then execute the actual receiver's input validator, calculation and complete
original-bound output validator. A template conflict requires explicit review.

Carry inherited and new issues into the receiver. A partial result, a valid
candidate hash or a successful JSON transformation never establishes native
financial semantics, approval, write authority or readiness to publish.
The installed package performs no automatic handoff or target invocation.
