# Native schema

All Phase 2 inputs carry schema_version=ir-phase2/1.0, request_id,purpose=internal-research,audience=internal-review,subject{type,id,issuer_id for security},as_of,use_on,knowledge_cutoff,information_barrier,sources[],top-level evidence_refs[],unresolved_issues[]. Use an aware timestamp cutoff for intraday spread comparisons; a date-only cutoff cannot support that comparison. Every row citation must be nonempty, registered and also declared at top level for source permission/time gating. Supplied future or ineligible evidence withholds the result projection. The example is synthetic; no entitlement or authenticity is asserted.

`issuer_profile` is nonfinancial-corporate. `prior` and `current` are reported financial observations, with explicit currency,unit,accounting_basis,consolidation_scope,period,evidence_refs; nullable EBITDA,gross_debt,unrestricted_cash,interest_expense,mandatory_capex,available_committed_facilities,near_term_maturities; boolean maturity_inventory_complete. Each period must end on or before both economic `as_of` and the knowledge-cutoff date (UTC for an aware cutoff). Forecast/scenario financials are unsupported. Prior must precede current with matching calendar,currency,unit,basis,scope and comparable duration. `thresholds` has leverage_increase_x,coverage_decline_x,spread_widening_bps. `events[]` carries kind,text,evidence_refs.

Optional `prior_spread`/`current_spread` carry security_id,currency,basis,spread_bps,evidence_refs and an aware intraday `observed_at` timestamp (for example `2026-10-20T16:00:00Z`). A comparison also needs explicit `spread_freshness_policy{max_current_age_hours}`: a finite nonnegative number of elapsed hours measured from the current observation to `knowledge_cutoff`. There is no default institutional freshness limit. Zero permits only an observation exactly at cutoff. The age limit applies to the current quote, not the intentionally historical prior quote.

Comparable quotes require exact security/currency/basis equality; strictly increasing observation instants; both instants on or before cutoff; and observation UTC calendar dates on or before economic `as_of`. Each quote's cited source/version must carry an aware `known_at` timestamp on or after that quote's observation. Source publication may legitimately follow observation and must remain eligible under the common cutoff gate. Date-only source knowledge cannot establish this ordering and is not promoted to midnight.

Missing observations/policy, insufficient source time precision, stale or unordered/future observations, and quote-key mismatches produce a partial result with `spread_change_bps: null` and no spread-widening alert. Valid financial metrics remain available. A supplied malformed/naive observation timestamp or malformed/negative policy is an input error. Absence of both optional spread rows requests no comparison. `source.known_at` never substitutes for `observed_at`.

See the paired JSON fixtures under evals/files; the separately retained original is mandatory for output reconstruction.
