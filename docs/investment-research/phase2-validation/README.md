## What the tests establish

The new suites exercise independent financial arithmetic, requested-coverage and
missingness states, source rights/timing/identity, formula recomputation, full
original-input reconstruction, mutations/deletions/additions, strict JSON parsing
and actual public command entrypoints. Every expanded/new method rejects duplicate
keys through input, calculation and output commands with a controlled diagnostic.
Negative evidence cannot pass because of a traceback or missing dependency.

tools/test_ir_model_reviewer_parity.py compares exact legacy JSON and independently
checks residuals and structural breaks. The original auditor source is archived
byte-for-byte; prefixed native resources and explicit mode preserve continuity.

tools/test_ir_adapters_phase2.py exercises all five mappings through actual installed
producer/receiver validation and reconstruction, verifies expected cash-flow and
headroom math, rejects context/rights/tampering conflicts, preserves issues and
share/timing basis, and rejects populated fields that would lose receiver data.

The portable runner strips PYTHONPATH/PYTHONHOME and copies each of the 36 packages
outside the repository. Independent forward review also copied the router outside
the repository and exercised its bundled handoff tool against an explicitly supplied
installed library path. Separately installed analytical methods remain dependencies;
the router neither installs nor silently launches them during route planning.

## Reproduction

Use Python 3.10+; the complete suite ran on 3.12.14. Repository frontmatter validation
also needs PyYAML. No analytical package requires a third-party Python library.

```sh
python3 -B tools/validate_skills.py
python3 -B tools/check_handoffs.py
python3 -B tools/check_investment_research.py
python3 -B tools/build_investment_research_index.py --check
python3 -B tools/sync_investment_resources.py --check
python3 -B tools/check_asset_management.py
python3 -B -m unittest discover -s tools -p 'test*.py'
python3 -B tools/run_investment_research_portable.py --report /tmp/ir-phase2-portable.json
python3 -B tools/check_ir_phase2_preservation.py docs/investment-research/phase2-validation/source-baseline.json
```

The older skill-creator quick validator rejects the repository's supported compatibility
frontmatter key. The repository validator explicitly validates it and passed all 387
skills; no checker was weakened. PyYAML was provisioned only in a temporary isolated
validation environment. Query-only eval entries remain specifications unless exercised
in the retained forward cases.

The [run manifest](run.json) pins current package manifests, code/registry and evidence
hashes and the pre-edit baseline. The baseline contains 17,892 source-file digests.
The initial checkout was already dirty; the audit attributes this phase through source
bytes and an explicit scope rather than the aggregate Git diff. Phase 1 validation
records are unchanged. Repeat saved-catalog generation is byte-identical, but the
external authoritative workbook was not reloaded. No live source authentication,
licensing service, institution approval, practitioner sign-off or production action
is established by these checks.
