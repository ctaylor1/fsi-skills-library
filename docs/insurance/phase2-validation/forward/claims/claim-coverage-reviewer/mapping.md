# Raw-source to native-input mapping

| Native field | Raw basis |
|---|---|
| Policy identity/wording/trigger/dates | POLICY; calendar convention retained |
| Insured/loss date | NOTICE; loss date is the reported date, not verified onset |
| F-NOTICE and F-PLUMBER | Exact source quotations, not asserted proven facts |
| G1 and X1 | Exact synthetic policy excerpts |
| Hypotheses and support/contrary links | Analyst interpretation explicitly distinguished from quotations; both competing evidence directions preserved |

Source registry paths and SHA-256 values bind each native source_ref to the exact raw artifact. Source_ref/version values are synthetic identifiers; hashes establish file identity, not truth. Missing amounts remain null. No example, evaluation, golden answer, or prior audit was read to design this case.
