# Native method and limits

Native tasks contain task_id, description, owner, state, due_date, deadline_basis, dependencies and source_refs. Completion or waiver requires completion_evidence. A missing predecessor, duplicate ID or cycle is malformed input and rejects computation. Other missing evidence is a visible data gap. Tasks retain dependencies and are ordered by supplied due date; overdue work remains visible when dependencies block it. Deadline basis is either a reviewed rule profile or an internal service target. There are no hardcoded statutory days, holiday calculations or inferred deadlines. Supply the reviewed resulting date and applicable rule evidence. A specialist must consider urgent claimant needs, preservation of evidence, coverage/liability investigation, expert appointments, fraud referral confidentiality, reserve review, communications, settlement authority and recovery rights. The script organizes the supplied plan and does not claim to invent every required investigation task.
