# Phase 5 primary-source boundaries

Reviewed 2026-10-04. These sources informed workflow separation and evidence
requirements. They do not supply complete, current institution/jurisdiction rules.
Actual rule profiles must retain their own version, applicable dates, program,
product, review evidence and source locator. Synthetic thresholds are not law.

| Primary source | Supported design boundary |
| --- | --- |
| [NAIC: Parametric Disaster Insurance](https://content.naic.org/insurance-topics/parametric-disaster-insurance) | Contract-defined parameter and payout, designated event verification and basis risk; an event alert is not a payment decision. The topic page is not adopted local law. |
| [ASOP 8: Regulatory Filings for Health Plan Entities](https://www.actuarialstandardsboard.org/asops/regulatory-filings-health-plan-entities/) | Health actuarial review considers population, claims, expenses, trends and contract/benefit effects; the package does not implement a universal approved rate formula. |
| [CMS: Unified Rate Review Instructions](https://www.cms.gov/files/document/unified-rate-review-instructions.pdf) | Member-month exposure needs a defined basis; an enrollment snapshot is not interchangeable. A descriptive incurred/premium ratio is not statutory rebate MLR. The mutable publication requires actual filing-year capture. |
| [CMS: Interoperability and Prior Authorization Final Rule fact sheet](https://www.cms.gov/newsroom/fact-sheets/cms-interoperability-prior-authorization-final-rule-cms-0057-f) | Program, service type and implementation provisions differ. Operational and API dates are distinct; drug and plan-type exceptions prevent one universal clock. This package requires the actual supplied administrative rule. |
| [CMS: Medicare NCCI FAQ Library](https://www.cms.gov/medicare/coding-billing/national-correct-coding-initiative-ncci-edits/medicare-ncci-faq-library) and [NCCI edits](https://www.cms.gov/medicare/coding-billing/national-correct-coding-initiative-ncci-edits) | Coding edits do not establish medical necessity or authorization. Exact quarterly/replacement versions and explicit payer adoption are required. No licensed code tables are bundled. |
| [AMA: CPT licensing FAQ](https://www.ama-assn.org/practice-management/cpt/cpt-licensing-frequently-asked-questions-faqs) | Electronic and AI uses can involve licensing requirements. Fixtures use opaque invented codes; supplied production content needs verified use rights. |
| [CMS: Medicare Advantage and Section 1876 Cost Plan Network Adequacy Guidance, December 9, 2024](https://www.cms.gov/files/document/medicare-advantage-and-section-1876-cost-plan-network-adequacy-guidance-12-09-2024.pdf) | Provider specialty, geography, eligible population, metric and exceptions matter. A supplied test is not certification or a rule transferable to another program. |
| [CMS: NPPES dissemination](https://download.cms.gov/nppes/NPI_Files.html) | NPI identity does not establish licensure or credential status; contract, credentials and directory observations need separate evidence. |

The package source maps describe the specific local mapping responsibilities.
Clinical criteria and real coding content must be supplied by authorized owners;
source statements, completeness flags and reviewer names are evidence assertions,
not independently authenticated approvals.
