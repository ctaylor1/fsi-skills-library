# Asset management source and method governance

Phase 1 establishes a reusable evidence discipline. It does not implement a universal
regulatory rules database, a verified source connector or complete jurisdiction packs.
Institution-specific policy, mandate, legal and valuation decisions need accountable
owners and current, applicable source evidence.

| Evidence | Required owner and record | Package behavior |
|---|---|---|
| Mandate / restriction | Investment compliance; applicable portfolio, rule scope, version and effective date | Apply only supplied supported rules; distinguish not applicable, missing and unsupported |
| Holdings, cash, NAV and transactions | Investment operations / designated book owner; basis, units, currency, time and source | Reconcile compatible observations; preserve unknowns and neutral correction alternatives |
| Prices / valuation hierarchy | Valuation committee / price control; method, source, observation and review evidence | Challenge supplied evidence; never set an official price or strike NAV |
| Research / disclosures | Investment Research; source version, economic date, known-at date and permitted use | Preserve point-in-time evidence and unresolved interpretation |
| Marketing / DDQ library | Product and compliance; fund/share-class identity, content approval and expiry | Withhold unsupported, stale, mismatched or restricted claims |
| Stewardship | Stewardship owner; applicable mandate/policy, entitlement and reviewed precedent | Assemble evidence and check a human proposal; never decide or submit a vote |
| Models / engines | Model owner and independent reviewer; method/version, reference cases and acceptance scope | Label bounded method and origin; require explicit engine contract for extensions |

“Approved” in a supplied record is an assertion requiring deployment verification.
Source indexing does not grant access, authenticate a publisher or prove a license.
A connector must retain the source artifact/version and permission evidence; use of
the declared research purpose must be checked by the deploying institution.

Numeric benchmarks should be independently constructed from the method specification,
include boundary cases and reconciliations, and state tolerance and units. A golden
regenerated from implementation is only a regression fixture. Do not count it as an
independent numerical benchmark or professional acceptance.

Jurisdiction maintenance must distinguish published, proposed, effective, delayed
and superseded requirements, with applicability and retrieval dates. The references
already present in each package are source-discovery pointers, not a certified current
legal opinion. Preserve the distinction between statutory diversification, contractual
limits, performance presentation standards, and valuation policies. The Phase 1 methods
do not infer a universal compliance result from a single threshold or checklist.

Release review requires source fidelity, audience isolation, routing/native interface
checks, independent calculation cases, professional review and deployment controls.
These gates remain separate even when all executable tests pass.
