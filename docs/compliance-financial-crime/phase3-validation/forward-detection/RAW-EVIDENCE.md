# Independent raw evidence and expectations

Prepared before native package execution. These are de-identified synthetic institution packets,
created from the documented input shapes, not copied source facts or golden results. All assertions
remain supplied/unverified. No real customers, sanctioned identities, legal ground truth or actions.

S3: two feeds/four unique input records, one declared snapshot loaded five minutes after effective
time, one four-case purposive labeled challenge set with independent source records for labels and
engine exports, ten supplied control workpapers. Manual confusion accounting TP2/FP1/TN1/FN0.
The forward variants probe missing receipts, duplicate identities, exact rate precision, hindsight
labels, unknown labels, source permissions, native scope, list version/delay and source divergence.

M1: a proposed three-day rapid wire-outflow pattern with exact event grain, reviewed namespace,
source-bound customer crosswalk, disjoint backtest/holdout IDs/dates, gross USD totals and human
change/shadow/rollback plans. An unrelated benchmark is retained as a reference. No execution has
occurred. Variants probe ambiguous identity, holdout item/dataset leakage, exact amounts, accounting
basis, engine population, benchmark substitution, unknown grain, SAR access and duplicate intake.

Every original raw intake and before-run expectation is frozen separately. Scripts run only the
package-native offline helpers; no reviewed package files are edited. Native outputs are validated
against detached originals and findings are compared to independently stated expectations.
