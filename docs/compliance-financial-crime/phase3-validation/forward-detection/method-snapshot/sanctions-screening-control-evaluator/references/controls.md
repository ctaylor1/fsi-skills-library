# Screening workpaper controls

Read-only intake controls enforce actual object/context, source-specific access, cutoff and exact field/fact mappings. Structural errors stop calculation; source/fact conflicts, unknowns, future receipts and stale evidence withhold dependent measurements.

Use the institution's reviewed requirement and workpaper procedure for each control dimension. Resilience evidence can cover outages, failover/compensating controls, replay/backlogs and recovery; the native helper checks supplied scope, timing and recorded outcomes, without simulating outages or declaring resilience. Vendor evidence can cover service/version, change governance and tested agreements; it is supplied evidence, not authenticated vendor assurance. Latency limits and measured observations must be explicit decimal strings. No numerical default is bundled.

A qualified owner reviews feed exclusions, missing fields/scripts, expected-list version/entry reconciliation, update lag, testset coverage, label reference quality, matching/normalization/transliteration evidence and exception causes. The tool does not generate labels from alerts, score confidence or list names. Sampling representativeness and statistical inference require a separately accepted method. Independent assurance requires a separate mandate, independence assessment and professional testing; labeling a review independent does not confer those properties.

Output integrity uses the bundled unchanged foundation/2.0 and native_integrity/1.0.0. Retain the original JSON separately and validate exact reconstruction before human narrative. Output edits, additional fields, embedded input and asserted actions fail. Hashes show supplied-input identity only. No execution channel is implemented.
