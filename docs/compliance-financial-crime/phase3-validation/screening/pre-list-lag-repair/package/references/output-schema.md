# Native output schema

The immutable output uses `compliance-foundation/2.0`, skill `sanctions-screening-control-evaluator`, method `supplied-screening-control-reconciliation/1.0`, and the same actual request/object/context, dates, role, classification and audience as the retained original. Foundation adds exact claim bindings, input hash, source references, unresolved issues, limitations and professional handoff routes. `source_truth=unverified`, `source_assurance=supplied-unverified`, `draft=true`, `human_review_required=true`, `action_taken=false`, `approval=not_requested`, `execution=not_performed` are required. Native raw source input is forbidden.

`status` is `needs-evidence` when retained issues exist, otherwise `draft-for-human-review`. Status is not professional acceptance. `results` includes source-resolved review/configuration, feed/list reconciliation, per-test eligibility/classes/latency, supplied control observations, all engine outcome counts, distinct measured TP/FP/TN/FN counts, unlabeled/ineligible counts, unmeasured cases/dimensions and supplied coverage/criteria flags. FP and FN rates are exact integer numerator/denominator/fraction objects; denominator zero yields null fraction and no favorable rate comparison. Sample comparisons may exist on eligible subsets while overall coverage remains incomplete.

`within_supplied_review_criteria` is null unless the full supplied scope/coverage, latency evidence, controls and both sample-rate criteria are complete. Coverage is distinct from passing results: an observed failure can have complete coverage and yield false criteria. `operational_effectiveness=not-established`, `legal_exposure=not-determined`, `match_identity_disposition=not-determined`, `independent_assurance=not-issued`, and engine/current-list/statistical-inference states `not-performed` remain explicit.

The [machine schema](output-schema.json) records the native shape. The executable validator reconstructs every field from the separately retained original, so edits, inserted narrative/keys, altered counts, source claims, self-hashes, embedded inputs or actions fail. Machine shape validation alone is insufficient. [Golden](../evals/files/output_golden.json), [partial](../evals/files/output_partial.json) and [tampered](../evals/files/output_tampered.json) outputs are synthetic validation artifacts.
