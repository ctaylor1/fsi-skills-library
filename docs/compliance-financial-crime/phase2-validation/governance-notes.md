Implementation date: 2026-10-03. Scope: seven new packages only; shared helper, catalogs,
router and synchronization are integrated by the root implementation owner. No commits,
live source collectors, system writes, filings, approvals or notification actions occurred.

## Distinct native methods

| Package | Actual native subject type | Bounded method and principal limitation |
| --- | --- | --- |
| compliance-program-designer | compliance_program | Mandate/risk/control/accountability/resource linkage and supplied-unit resource difference; no adequacy or operating-effectiveness determination. |
| regulatory-applicability-reviewer | regulatory_perimeter | Multi-rule/entity explicit all/any comparisons with exact reviewed profile, lifecycle and permissions inventory; no national legal default or final legal ruling. |
| regulatory-source-monitor | regulatory_source_docket | Baseline/current snapshot comparison, source collection coverage, dates and supersession questions; no live feed, scheduler or guarantee of complete legal developments. |

| compliance-financial-crime-risk-assessor | institution_compliance_risk | Separate dimension-level inherent, control and residual indicators under an explicit supported accepted method; illustrative weighted multiplicative policy is not law or calibrated universal risk. |
| compliance-business-change-reviewer | business_change | Exact scoped dependency graph, predecessor propagation, dated release review and unresolved exceptions; no launch authorization or automatic waiver. |
| compliance-program-effectiveness-reviewer | compliance_program_review | Denominator-preserving coverage/outcome/quality/resources/activity evidence with measurement universe, scope/period/definition limits; activity reduction never demonstrates effectiveness and independence is not inferred from a role. |

Every package carries substantive professional workflow instructions, source map, controls,
handoffs, output template, local domain logic, input/calculation/output scripts, synthetic
normal/bad/tampered fixtures, golden output, executable evaluation manifest and changelog.
The shared foundation and native-integrity resources are bundled rather than imported from
sibling packages. Claims use exact detached source registry facts. Profile/method/snapshot,
relationship and release evidence bind the parameters and scope actually evaluated.
Common claim bindings retain input-path/source/fact locators without copying raw values;
locator consistency does not establish semantic truth or automatic conclusion support.
